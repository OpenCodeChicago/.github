## ✨ About

This repository is designed to **keep project-wide files organized**. It acts as a **central hub** for:

* 📝 Issue templates
* 🔀 Pull request templates
* 📖 Community guidelines
* 🙌 Standard contributing practices

By having all of these files in one place, we ensure that contributors work with the **same standards, clarity, and best practices** across all repositories.

---

## 📂 Project Structure

Here’s a quick look at the repo layout:

```bash
.github/
├── ISSUE_TEMPLATE/           # 📝 Custom issue templates
│   ├── bug_report.md         # Report bugs
│   └── feature_request.md    # Suggest features
├── PULL_REQUEST_TEMPLATE.md  # 🔀 PR submission guidelines
├── CODE_OF_CONDUCT.md        # 📖 Community behavior rules
├── CONTRIBUTING.md           # 🙌 Contribution guide
└── README.md                 # 📘 This file
```

## ⚙️ Purpose

The **.github** repository exists to:

✔️ Keep **all repositories consistent**
✔️ Help new contributors **onboard faster**
✔️ Provide a **clear workflow** for issues & PRs
✔️ Foster a **welcoming open-source community**

Think of it as the **rulebook + guidebook** for the entire organization.

## 🤝 Contributing

We **welcome all contributions** — whether big or small! 🎉

### Steps to contribute:

1. 🍴 Fork the repo
2. 🌱 Create a new branch (`feature-branch`)
3. 🛠️ Make your changes
4. ✅ Commit your work
5. 🔀 Open a Pull Request

Please make sure to read the [CONTRIBUTING.md](./CONTRIBUTING.md) before getting started.
